## 🧩 Features

Includes all core features from the original mod:

* Copy & Paste hotkeys
* Design catalogue
* Auto material handling
* Undo system
* Material swapping
* Queue chiselling
* Additional tool modes
* Image → design tool
* QR code generator

---

## ✨ How it works

This is a **client-side mod**, meaning:

* It **cannot instantly modify blocks**
* Instead, it performs chiselling by simulating the required steps automatically
